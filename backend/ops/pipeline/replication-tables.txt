# main → dev·prod 복제 대상 분류. replicate.sh가 읽고, ReplicationTableClassificationTest가 Flyway 스키마와 비교한다.
# 새 테이블을 만들면 replicate 또는 exclude 중 하나에 반드시 적는다. 어느 쪽에도 없으면 ./gradlew test가 실패한다.
#   replicate <테이블>  main 값으로 대상 DB의 테이블을 통째로 바꿔 끼운다 (서빙이 읽고, 대상 DB에서 쓰지 않는 것)
#   upsert <테이블>     main 행을 추가·갱신만 하고 지우지 않는다. 다른 테이블이 외래 키로 가리켜 바꿔 끼울 수 없는 카탈로그용
#   exclude <테이블>    복제하지 않는다 (대상 DB가 쓰거나, 서빙이 읽지 않는 것)
